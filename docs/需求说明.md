# for-mark 需求说明（v0.1 草稿）

> 状态：草稿，待确认
> 本文档的作用：确定版本范围，防止开发过程中范围膨胀。每个功能必须归入某个版本或"不做"。

## 1. 项目概述

一个跨平台（macOS / Windows）的 Markdown 所见即所得编辑器，交互对标 Typora：
单栏编辑、语法符号在光标离开后隐藏、支持 Mermaid 图表的实时渲染。

- 产品名称（暂定）：for-mark
- 目标用户：需要写带图表的 Markdown 文档的个人用户（开发者、学生、文档作者）
- 核心差异化：Mermaid 实时渲染体验流畅，中文输入体验一流

## 2. 技术栈（已确定）

| 层 | 选型 |
|---|---|
| 桌面壳 | Electron |
| 语言 | TypeScript |
| 构建 | Vite + electron-builder |
| 编辑器内核 | Milkdown（ProseMirror） |
| 源码块编辑 | CodeMirror 6 |
| 图表 | Mermaid（npm，懒加载） |
| 数学公式 | KaTeX |
| IDE | VS Code |

## 3. 功能需求与版本划分

### v0.1（MVP：内核验证版，纯网页，先不套 Electron 壳）

目标：验证编辑器手感与 Mermaid 渲染，跑通核心体验。

- [ ] 编辑区：单栏所见即所得编辑
- [ ] 基础语法渲染：标题、粗体/斜体/删除线、行内代码、链接、引用、有序/无序列表、任务列表、分隔线
- [ ] 代码块：语法高亮 + 光标进入显示源码、离开渲染高亮
- [ ] **Mermaid 代码块实时渲染**（核心）：输入防抖 300ms、语法错误时保留旧图并提示、SVG 缓存、点击图进入源码编辑
- [ ] 图片：`![]()` 语法渲染、粘贴图片插入
- [ ] 表格：GFM 表格编辑
- [ ] 深色/浅色主题切换（Mermaid 主题联动）
- [ ] 文件打开/保存（浏览器阶段用 localStorage + 手动导入导出过渡）

明确不做：登录、云同步、协作、移动端。

### v1.0（桌面版，可以日常自己用）

目标：套上 Electron 壳，成为真正能用的桌面软件。

- [ ] 本地文件系统：打开/保存 .md、最近文件、修改未保存提示
- [ ] 文件树侧边栏（打开文件夹）、标签页多文件
- [ ] 源码模式（整篇源码编辑，CodeMirror 6）与 WYSIWYG 模式切换
- [ ] 导出：HTML、PDF（打印方案）
- [ ] 数学公式（KaTeX）、脚注、YAML front-matter 显示
- [ ] 查找与替换
- [ ] 大纲面板（标题导航）+ 字数统计
- [ ] Mac / Windows 打包与图标
- [ ] 自动保存

### v1.x（打磨与增强，按需排序）

- [ ] 自动更新
- [ ] 多主题 / 自定义 CSS 主题
- [ ] 图片管理：本地资源文件夹、图床上传
- [ ] 目录生成（TOC）
- [ ] 快捷键自定义
- [ ] 导出 Word / 图片
- [ ] 多语言界面（中文/英文）
- [ ] PlantUML 等其他图表语言

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 中文输入法 | 编辑器所有交互路径下 IME 组合输入正常（光标不跳、不丢字）——开发期持续用中文输入法测试 |
| 性能 | 1 万字 + 10 个 Mermaid 图的文档，输入无可感知卡顿（<16ms 帧预算按块增量渲染） |
| 跨平台 | Mac 与 Windows 行为一致（Electron 保证内核一致，需统一快捷键差异，如 Cmd/Ctrl） |
| 安全 | Mermaid `securityLevel: 'strict'`；渲染 HTML 过滤 XSS |
| 大文件 | 100KB 以上文档打开时间 < 2s |

## 5. 里程碑（初步）

1. M1：网页内核 MVP（v0.1 清单全部完成）→ 自测体验
2. M2：Electron 壳 + 本地文件读写
3. M3：v1.0 功能补齐，双平台打包
4. M4：日常自用一个版本周期，收集问题后进入打磨
